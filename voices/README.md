# صوت Piper العربي (أوفلاين)

1. `pip install piper-tts`
2. نزّل الملفين دول وحطهم في الفولدر ده:
   - https://huggingface.co/rhasspy/piper-voices/resolve/main/ar/ar_JO/kareem/medium/ar_JO-kareem-medium.onnx
   - https://huggingface.co/rhasspy/piper-voices/resolve/main/ar/ar_JO/kareem/medium/ar_JO-kareem-medium.onnx.json
3. افتح الإعدادات ← الصوت ← محرك الصوت.

> الصوت ده عربي فصيح بنَفَس أردني، مش مصري. علشان كده الوضع **تلقائي** بيستخدم Edge المصري، ويرجع لـ Piper بس لما النت يقع.
> لو عايز صوت أوفلاين أسرع على الأجهزة الضعيفة، استخدم `ar_JO-kareem-low`.
