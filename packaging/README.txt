يوبي — مساعد صوتي بالمصري للويندوز
=====================================

التثبيت (دقيقة واحدة)
---------------------
1. فك الضغط عن الملف ده كله في أي مكان (كليك يمين ← Extract All).
2. دبل كليك على  Install Yobi.cmd
   - لو ظهرت رسالة زرقا "Windows protected your PC": دوس More info ← Run anyway.
     (يوبي مش موقّع من مايكروسوفت، فالويندوز بيحذّر من أي برنامج زيه.)
3. يوبي هيتنسخ لحسابك (من غير صلاحيات أدمن)، وهتلاقيه على سطح المكتب وفي قايمة ابدأ.

أول تشغيل: مفتاح Gemini المجاني
-------------------------------
يوبي محتاج مفتاح من جوجل عشان يفكر. مجاني وبياخد دقيقة:
1. افتح  https://aistudio.google.com/apikey  وسجّل دخول بحساب جوجل.
2. دوس Create API key، وانسخ المفتاح (بيبدأ بـ AIza أو AQ.).
3. حطه في الشاشة اللي يوبي هيفتحها أول مرة، ودوس "يلا نبدأ".

من غير مفتاح خالص: دوس "كمّل من غير مفتاح". يوبي هينفذ الأوامر بس (افتح واقفل البرامج والألعاب
والمواقع، الصوت، الأغاني، الإضاءة، سكرين شوت، فكرني بعد…، الساعة كام) بموديل صغير شغال على جهازك،
بيتعلم أسامي البرامج والألعاب اللي عندك. الدردشة والأسئلة محتاجة المفتاح. ولو النت فصل وإنت معاك
مفتاح، يوبي برضه بينفذ الأوامر دي.

اختياري: مفتاح Groq ( https://console.groq.com/keys ) بيخلي يوبي يسمعك أسرع.
تقدر تغيّر المفاتيح بعدين من قايمة ابدأ ← Yobi ← Yobi - API keys.
المفاتيح بتتحفظ على جهازك بس.

إزاي تكلّمه
-----------
- قول «يا يوبي» وبعدها الأمر، أو دوس  Ctrl + Alt + Y  وكلّمه.
  (النداء بالصوت متدرّب على صوت واحد، فلو مش بيسمعك كويس استخدم الزرار.
   تقدر تخليه بالزرار بس من الإعدادات ← الاختصار والشاشة ← تنده على يوبي إزاي.)
- الزرار طويل؟ غيّره من الإعدادات ← الاختصار والشاشة ← زرار النداء، واختار أي زرار (مثلاً F8).
- أمثلة: افتح يوتيوب، شغّل سبوتيفاي، علّي الصوت، اقفل كروم.
- الجزيرة اللي فوق في الشاشة: دوس عليها أو  Ctrl + Alt + I  عشان تفتحها، وفيها الإعدادات.

المتطلبات
---------
- ويندوز 10 أو 11 (64 بت)، ومايك، ونت.
- Microsoft Edge WebView2 (موجود في ويندوز 11، ولو ناقص البرنامج هيقولك تجيبه منين).
- حوالي 1 جيجا مساحة. أول مرة يوبي يحتاج يسمع من غير نت هينزّل موديل صغير (حوالي 500 ميجا).

لو حصلت مشكلة
-------------
- يوبي بيكتب كل حاجة في:  %LOCALAPPDATA%\Programs\Yobi\app\logs\yobi.log
  ابعت الملف ده لصاحب البرنامج.
- مش بيسمعك؟ اتأكد إن المايك مسموح: إعدادات ويندوز ← الخصوصية ← المايكروفون.
- عايز تشيله: قايمة ابدأ ← Yobi ← Uninstall Yobi (أو من إعدادات ويندوز ← التطبيقات).

التحديث: فك نسخة أحدث ودوس Install Yobi.cmd تاني. مفاتيحك وإعداداتك هتفضل زي ما هي.
